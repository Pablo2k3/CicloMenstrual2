# Instrucciones del proyecto

## Documentación obligatoria

Cada cambio realizado en el proyecto debe documentarse en la misma entrega.
Esto incluye cambios de código, comportamiento, reglas de negocio, interfaz,
persistencia, notificaciones, dependencias y pruebas.

Antes de dar por terminado un cambio:

- actualiza el README o el documento específico afectado;
- registra las nuevas decisiones, limitaciones o tareas pendientes en
  `docs/tareas-pendientes.md` cuando corresponda;
- mantén coherentes la documentación funcional, la arquitectura, las reglas de
  negocio y la trazabilidad;
- si el cambio no requiere modificar documentación, deja constancia explícita
  del motivo en la entrega.
